# Portfolio de Julián Larrosa

Portfolio personal orientado a conseguir una primera oportunidad como desarrollador backend.

## Tecnologías

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Cómo abrirlo

1. Abrí la carpeta con Visual Studio Code.
2. Instalá la extensión **Live Server**.
3. Hacé clic derecho sobre `index.html`.
4. Seleccioná **Open with Live Server**.

También podés abrir `index.html` directamente en el navegador.

## Datos que debés reemplazar

Buscá estos textos en `index.html`:

- `TU_LINKEDIN`
- `TU_EMAIL`
- `URL_REPOSITORIO_ESRE`
- `URL_REPOSITORIO_FUTBOL`

Agregá tu CV dentro de la carpeta con el nombre:

`cv-julian-larrosa.pdf`

## Estructura

```text
portfolio-julian-larrosa/
├── index.html
├── styles.css
├── script.js
├── cv-julian-larrosa.pdf
└── README.md
```


## Foto de perfil

Guardá tu foto dentro de la carpeta `images` con este nombre exacto:

`profile.jpg`

La imagen se mostrará automáticamente en formato circular.
